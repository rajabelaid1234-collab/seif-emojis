# SEIF EMOJIS Keyboard for Android

Android keyboard prototype built with Android's InputMethodService.

## Install and enable
1. Download the APK from the repository's Releases page after the automated build succeeds.
2. Install it. Android may ask permission to install apps from the browser or file manager used to open the APK.
3. Open SEIF EMOJIS Keyboard and tap **تفعيل لوحة المفاتيح**.
4. Enable SEIF EMOJIS in Android settings.
5. Tap **اختيار لوحة SEIF** and select SEIF EMOJIS.
6. In a text field, switch keyboards using the system keyboard selector.

This prototype has a bundled set of faces and does not request internet access. Text is inserted into the active field using Android's InputMethod API. Use care when choosing third-party keyboards for sensitive information.
